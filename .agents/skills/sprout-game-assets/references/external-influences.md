# External workflow influences

This skill adapts general principles rather than copying external implementation text:

- Pixel Art Sprites, Apache-2.0: deliberate pixels, 1x readability, stable limited palettes, fewer purposeful animation frames, and seamless tile review.
  https://github.com/omer-metin/skills-for-antigravity
- Everything Game Dev Code, MIT: explicit sprite-pipeline inputs, procedural validation gates, art-language discipline, and QA matrices.
  https://github.com/MRCalderon3D/everything-game-dev-code
- SpriteCook Agent Skills, MIT: immutable provider asset identifiers, local manifests, presigned downloads, and source-first animation workflows.
  https://github.com/SpriteCook/skills

Sprout-specific repository contracts and PixelLab tools remain authoritative.
