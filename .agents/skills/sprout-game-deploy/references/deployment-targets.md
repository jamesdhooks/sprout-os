# Deployment targets

| Target | Purpose | Evidence limit |
| --- | --- | --- |
| Windows native | Fast runtime and launcher iteration | Does not prove Miyoo services, input, or performance |
| Licensed desktop PICO-8 | Cart behavior, storage, token/cart compiler | Does not prove fake-08 or Onion integration |
| Onion SD card | File layout and catalogue installation | Does not prove launch unless booted |
| Miyoo fake-08 | Required PICO compatibility path | Validate input, pacing, audio, persistence, return |
| Miyoo licensed wrapper | Optional paid-runtime path | Never redistribute licensed binaries/data |
| SSH deployment | Rapid device iteration | Preserve unrelated SD-card content and verify installed paths |
